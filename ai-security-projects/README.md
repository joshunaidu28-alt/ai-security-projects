# AI Security Projects

Four small, working security tools that use AI-era ideas, each runnable offline.

| Project | What it does |
|---|---|
| 1-scam-sms-detector | Flags Telugu-English scam SMS and explains why |
| 2-threat-report-to-sigma | Turns a threat report into Sigma rules and validates them |
| 3-agent-flight-recorder | Logs and flags risky AI agent tool calls |
| 4-prompt-injection-tester | Tests chatbots for prompt injection leaks |

Everything uses synthetic data and fake tools. Use only on systems you own.
